TouchVitals for Touch Bar Macs
★ GitHub
For your MacBook's Touch Bar

Network, CPU, memory, and disk.
Live on your Touch Bar.

Switch to an app with no custom Touch Bar layout and you get media keys, nothing else. TouchVitals pins four live stats to the Control Strip instead. Tap to expand. Works no matter what app is frontmost.

What it shows

one Control Strip slot, four metrics
↓↑

Network

Download and upload rate, color-coded blue and orange so you never mix them up at a glance.

▣

CPU

Overall load percentage, sampled every second straight from host_processor_info.

▤

Memory

Used percentage computed the way Activity Monitor does it: active, inactive, wired, and compressed pages.

▥

Disk

Capacity used on your primary volume, shifting amber past 80% and red past 95% so you notice before it's a problem.

⟳

Stays up

Keeps showing after you switch apps or open a Dock menu, re-asserting itself in about 200ms each time.

⋯

Menu bar control

A small status item toggles the history graphs, shows build info, and quits the app cleanly.

Build it yourself

built from source, five minutes start to finish
# clone and build
git clone https://github.com/jashjacob/touchvitals.git
cd touchvitals
swift build
# run the test suite
swift test
# launch it, then check the menu bar for the control icon
.build/debug/TouchVitals

Requirements

  • A physical Touch Bar Mac: Intel 13"/15"/16" (2016 to 2020) or Apple Silicon M1/M2 13" (2020 to 2022)
  • macOS 14 or later
  • Swift 6 toolchain (Xcode or Command Line Tools)
Built by Jash. Free and open source.
GitHub README CI

Reuses the reader/sampler/scheduler design from Vitals and the private Control Strip presentation layer from TokenBar. Depends on undocumented DFRFoundation APIs that Apple could remove at any time. Not affiliated with Apple.
